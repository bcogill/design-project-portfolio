# A2 – Truss Stress Analysis

## Objective
- Design a lightweight planar truss using A500 steel or an alternative material.
- We must create free body diagrams for all the joints and critical pins.
- Calculate the required cross-sectional area of truss elements with a safety factor.
- Determine all the pin sizes based on shear forces with a safety factor.
- Solve equations symbolically and numerically relating to CSA for both truss and pin design.
- Estimate the total weight of the truss and pins.
- Create a CAD model with similar dimensions and connections.
- Compare the CAD model weight predictions with our own hand calculations.
- Document some key engineering lessons that we have learned throughout the process/assignment.
